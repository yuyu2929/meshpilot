# BUSINESS — MeshPilot 的商业设计

## 一句话

**个人免费，商用付费**：核心算法对个人与非营利组织永久免费，
任何营利组织的使用（含核心层）都需要商业许可；企业级能力（批量流水线 / CI 报告 / SSO）另需 Ed25519 许可证与私有扩展包。

## 为什么是"实时渲染资产优化"

三个候选方向里选它，因为**企业付费意愿有商业先例**：

| 方向 | 先例 | 付费方 | 判断 |
|---|---|---|---|
| 实时渲染资产优化 | Simplygon（微软收购）、InstaLOD、meshoptimizer | 游戏/引擎/AR 工作室 | **最强**：预算是硬的（面数/绘制调用），减面直接换算成帧率和包体 |
| 3D 打印修复 | Meshmixer、Netfabb | 制造/医疗 | 有钱但市场小、认证壁垒高 |
| 通用 Mesh 健康诊断 | 无独立品类 | —— | 太窄，撑不起产品 |

Simplygon 被微软收购、InstaLOD 长期盈利，证明游戏行业愿意为
"批量资产优化流水线"付钱。付费点从来不是算法（QEM 论文公开 27 年），
而是：**批量、可集成、可验收**。

## 三层结构（open-core）

```
┌─────────────────────────────────────────┐
│ 企业层（付费）  batch_pipeline / ci_report / sso │
│ 挂载方式：MESHPILOT_LICENSE 环境变量        │
├─────────────────────────────────────────┤
│ SaaS 层（托管）  批量任务 / 团队协作 / 报告   │
├─────────────────────────────────────────┤
│ 核心层（个人/非营利免费，商用需授权）                      │
│ QEM 减面 / 诊断 / LOD / 质量验证 / CLI / Web │
└─────────────────────────────────────────┘
```

**为什么核心敢全开**：算法的护城河不在代码在闭环——诊断→处方→
执行→验证的产品化、平台预算库、CI 集成、审计报告。竞品可以抄
QEM（1997 年的论文），抄不走"每一刀都验收"的工程体系。个人开发者
免费拿到真东西，会成为宣传机器（Blender Decimate 的先例）；
企业付费买的是责任和集成。

## 定价逻辑（草案）

| 层 | 内容 | 价格 |
|---|---|---|
| 个人/小工作室 | 核心全部，本地 CLI + Web | 免费（非商业用途） |
| 团队版 | 批量流水线、CI 报告、Web 团队空间 | 按席位/月 |
| 企业版 | + SSO、审计、私有部署、SLA | 年约 |

关键设计：**核心不经许可门禁**。`meshpilot.enterprise.require()`
只拦企业功能；没许可证时 CLI/API 照常工作，只是企业按钮置灰。
任何许可证篡改静默降级社区版（Ed25519 签名，公钥随仓库分发，
私钥从不入库）。

## 分发与信任

- 仓库自包含：无外部资产文件，clone 即可跑 demo/测试——这是对
  "免费层是真东西"的最直接证明
- 测试 44 个全过是发布门槛；每个版本跑 `scripts/demo.py` 六段
- 基准数据写进 README 且标注采样底噪——不过度宣传是长期信任
